# Yaqoob Khan – Portfolio (Next.js)

## Run
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Edit
- Text / projects / skills / testimonials: `lib/data.js`
- Images: `public/assets/` (keep the file names or update `lib/data.js`)
- CV: add `public/assets/Yaqoob-Khan-CV.pdf`
- Social links & WhatsApp number: `lib/data.js` (`SITE`)
- Styles: `app/globals.css`
